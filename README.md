🧪 Prueba Frontend - React
📌 Requisitos Cumplidos

✅ Interfaz de usuario con al menos 3 componentes anidados.

✅ Uso de data binding para intercambio de información entre componentes.

✅ Implementación de ciclos de vida apropiados en cada componente.

✅ Consumo de datos desde API REST pública:
👉 https://jsonplaceholder.typicode.com/

✅ Implementación de un CRUD funcional utilizando los datos recibidos.

🧱 Estructura del Proyecto

    src/
    ├── components/
    │   ├── UserList.jsx        // Lista de usuarios (componente principal)
    │   ├── UserDetail.jsx      // Detalles de usuario (componente hijo)
    │   └── UserForm.jsx        // Formulario para editar/crear usuario
    ├── services/
    │   └── api.js              // Funciones para interactuar con la API
    ├── App.jsx
    └── index.js

🚀 Cómo Ejecutar el Proyecto
Clonar el repositorio:

    git clone https://github.com/tu_usuario/nombre_del_repo.git
    cd nombre_del_repo
    Instalar dependencias:

    npm install
    Ejecutar el servidor de desarrollo:
    
    npm start
    Acceder desde el navegador en:
    http://localhost:3000


🧠 Consideraciones Técnicas
Se usó React 18 y Vite o Create React App (dependiendo de tu setup).

Se usaron Hooks (useState, useEffect) para manejar estado y ciclo de vida.

Estilos aplicados con CSS puro / Tailwind / Bootstrap / Styled Components (según corresponda).

Todas las operaciones del CRUD están simuladas, ya que la API de jsonplaceholder solo permite GET reales.
